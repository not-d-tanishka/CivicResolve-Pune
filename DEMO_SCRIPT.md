2. (0:40) Open Complaints; filter Kothrud and show the fictional repeated pothole reports plus a streetlight report at a similar landmark.
3. (1:30) Register a second pothole report with matching category, Kothrud locality and same landmark.
4. (2:20) Generate duplicate candidates; explain the category/locality gate and that C++ text score only suggests review.

6. (4:00) Open Priority Queue and explain the 0–10 score components and tie rule.
7. (4:45) Update a complaint status, refresh/restart and show persistence/history.
